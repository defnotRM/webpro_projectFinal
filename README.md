# Suki Order System

โปรเจกต์ระบบจัดการออร์เดอร์ร้านสุกี้ (Final Project วิชา Web Programming)

## วิธีรันโปรเจกต์

1. ติดตั้งแพ็กเกจทั้งหมด
```bash
npm install
```

2. เปิด Terminal ตัวที่ 1 เพื่อรัน JSON Server (พอร์ต 3001)
```bash
npm run api
```

3. เปิด Terminal ตัวที่ 2 เพื่อรันเว็บฝั่ง Frontend (พอร์ต 5173)
```bash
npm run dev
```

4. เปิดเข้าเว็บได้ที่ `http://localhost:5173`
